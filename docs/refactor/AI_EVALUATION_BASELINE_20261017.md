项目并非完全没有评测：已有旧意图基线、shadow差异记录和40问RAG评测。本次补充统一运行、文档ID指标、失败保留和测量边界，未将旧实体命中率当作文档召回率。

入口：`node tools/ai-evaluation/run.mjs --run-id <新的唯一ID>`；工具回归：`node --test tools/ai-evaluation/*.test.mjs`。

新增50条意图、50条规划、100条知识检索与24条回答证据工具契约样本；每条保留原输入、预期、实际输出、检查项、耗时及评测 traceId。源码/数据 SHA256、运行日志和原始结果冻结在每次独立运行目录中。质量失败保留，JUnit成功只证明评测执行成功。

## 实测结果

| 范围 | 结果 | 解释 |
| --- | --- | --- |
| 单轮确定性分类器 | 30/45 标注字段完全匹配 | 不代表真实 LLM 意图准确率 |
| 两轮实际 preview，关闭 LLM | 1/5 标注字段完全匹配 | 真实续接链路，待逐例定位；没有实际状态写入 |
| 45条应规划请求 | 45/45非空，44/45静态估算可行 | 目录与静态组件，不是实时地图全流程 |
| 已标注需求与静态可行同时满足 | 40/45 | 仅需求子集，不代表完整自然语言满足率 |
| 5条缺条件请求 | 5/5按预期追问 | 与规划成功率分开 |
| 75条可答检索 | 文档 Recall@3/@5均1.0；MRR 0.9778 | 每城仅6篇，Top5接近全库，不能外推大库质量 |
| 25条应证据不足 | 拒绝8/25，错误放行17/25 | 门禁拒绝召回32%；错误放行68% |
| 75条可答与100条城市检查 | 误拒0/75，跨城市泄露0/100 | 仅本受控语料范围 |

意图50题合计31/50是两种测量路径的汇总，必须同时报告45单轮与5双轮，不能叫作“分类器整体准确率”。修改意图的27/35与禁止修改样本的1/5错误分类也是组件指标，不是错误写入率。

## 已暴露的缺口与下一轮顺序

1. 优先核验并修复证据门禁：即时活动5条、未知实体5条、宠物规则4条、未来保证3条被错误放行。当前实现对部分中文措辞及问题主体的证据覆盖不足；“检索到了同城资料”不等于支持问题结论。该结果不是最终模型幻觉率。后续修复须保留本基线，并使用新措辞、否定与未知主体作保留验证，避免逐句加正则。
2. 逐例核验双轮追问及单轮字段丢失。已有实际 preview 输出可定位“第二天”补答丢失等问题；关闭 LLM 路径失败不能直接断言启用真实模型时也失败。
3. 规划有1条 TIME_OVERLAP；北京、杭州、西安、武汉4条少走路请求缺少可证明需求满足的目录元数据。后者是数据/证明不足，不能直接说实际路线不适合老人。
4. 扩大并独立标注真实语料后，再固定同一候选预算比较 dense、关键词/BM25、融合及重排。当前数据不足以证明混合检索收益。

## 测量修正与审查透明性

run01因测试脚手架把目录辅助字段直接反序列化为领域对象而失败；仅修正测试加载，保留失败日志。run02完整执行后，独立复核发现两处测量问题，未通过改生产代码刷分：

- 规划v1五条“带父母”错误推导为低步行，v2仅移除这一预期，revisionJournal记录理由、原SHA与案例ID。run02原始数据和脚手架完整留存。规划36/45变为40/45是标签纠正，不是生产改善；独立时间重叠和4条目录元数据缺口仍保留。
- 追问v1直接调用续接函数并在返回null时回填原意图，不能代表真实预览。v2改为两次实际 PlanAdjustmentService.preview，只采纳实际响应，关闭模型，记录两轮请求、pendingIntent、决策及零写入证据。不得直接比较两版追问分数宣称提升。

## 尚未证明

标签由智能体拟定并经其他智能体复审，属于暂定标签，未经独立人类裁决。意图/规划各10个相关语义族，检索20个相关语义族，题数不等于独立统计样本。

检索语料30篇中25篇合成、5篇复用项目资源。本次实际走生产本地降级排序、临时SQLite和门禁，语义供应商明确不可用。真实LLM、dense、BM25、hybrid、供应商事实、完整HTTP规划及真实世界可行性均未运行。
