## 实现边界

- 原始问题先由 `SemanticEvidencePort` 抽取主体、属性、时间范围与结论类型；Java 校验完整字段、枚举、主体原文锚定及预算。检索扩展不参与需求判断。
- 同城市目录的规范名与已核验 aliases 用于身份解析；搜索关键词、附近地点和正文中的自称别名没有身份授权。
- 常规问题由第二次模型判断证据可回答性及覆盖度；Java 核验全部需求 ID、原文唯一引文和位置、主体匹配。正面和负面结论均可回答。CURRENT、DATED、GUARANTEE 不由静态知识给出结论。
- 任一阶段模型不可用、输出不合法、覆盖不完整、引用不合法或证据不足均 UNKNOWN。两个模型阶段各有 15 秒 Java 等待上限，检索时间另计；线程中断不能保证远端停止计费。
- UNKNOWN 仍检索同城来源，但不再调用生成模型。未核验的正文不能借“背景”标签泄出主结论；来源通道仅提供资料条目与实际存在的安全 http(s) 链接，没有核验的电话不提供。
- Java 验证的是结构、身份和引文出处；属性、否定、条件的语义绑定仍依赖模型，不能声称已经形式化证明。
- `/ai/rag/retrieve` 不再匿名开放；BFF 转发用户凭证。聊天原有授权边界没有在此轮全面重做。
