# AI 辅助标签评分修订与 rerank 采用门槛

**修订号：** `model-assisted-qrels-v1`  
**冻结日期：** 2026-10-18（Asia/Shanghai）  
**状态：** 已在计算本轮检索质量指标前冻结  
**适用数据：** 重庆盲池 pool-02、run-01 排名、80题/1,671候选

## 本轮标签来源与分歧规则

1. 本轮探索性 qrels 以 GPT-6 Luna 对 1,671 项的完整预标为主标签。其含义是“模型建议的相关性标签”，不是人工金标或事实真伪认证。
2. DeepSeek 同一模型的两轮结果只作第二来源检查，不作为两名独立标注员，也不以 2:1 多数票覆盖 Luna。
3. 对每个候选，若 DeepSeek 两轮都成功且彼此同分，则与 Luna 比较：同分标为 `CROSS_MODEL_AGREEMENT`；不同分标为 `CROSS_MODEL_DISAGREEMENT`。DeepSeek 两轮不一致或有一轮失败，标为 `DEEPSEEK_UNRESOLVED`。这两种状态保留两边原始等级、理由和引文。
4. 所有探索性质量指标均使用 Luna 主标签，不因交叉模型分歧而删改等级；分歧条数和按题汇总的严格全候选一致子集作为单独敏感性结果。无效 Luna 记录必须保持未判并使对应题不进入完整池指标。本轮冻结数据经校验为全量有效。
5. 不把任何 AI 结果写入 `HUMAN_SELF_ATTESTED` 格式，不称人工完成；全量人审、84条盲重标、一致性统计和生产启用条件仍未满足。

## Rerank 预先登记的决策规则

沿用 [原事前采用规则](RERANK_ADOPTION_RULE_20261018.md) 的质量和延迟阈值，不根据本轮分数调参。本文件进一步区分探索性评测与产品准入：

- 本轮用 Luna 主标签计算开发集与保留集分数、逐题配对胜负，以及严格跨模型一致题子集的敏感性结果。输出标记为 `MODEL_ASSISTED_EXPLORATORY`。
- 探索性结果无论好坏都不能通过人工标注门槛，也不能授权交互式 rerank。最终启用结论在本轮固定为 `INSUFFICIENT_NO_ENABLE`。
- 后续只有在人类标注完成后，保留集60题全部可评分、有效配对至少50题且覆盖至少25个 family、rerank 对 hybrid 的保留集 nDCG@5 宏平均绝对提升至少0.03、胜题数至少负题数2倍且胜负差至少6、按 family bootstrap 10,000次固定seed=20261018的95%区间下界严格大于0，并同时达到 CPU rerank 阶段 p95≤1,000ms 与真实端到端 TTFT p95≤5,000ms 时，才可进入启用讨论。所有条件均满足仍需单独验证 Java 主链路；本规则本身不授权部署。
- 比较唯一主要基线是 `hybrid_rrf`，候选方法为 `hybrid_rerank`，主质量指标 `nDCG@5`。每题先平均三轮，再在同一城市、同一 split 内宏平均。逐题配对在共同完整题上报告 WIN/LOSS/TIE，平局容差 1e-12；缺失结果、未判候选或候选池覆盖问题均列出并排除，不能假定为0。
- 开发集20题用于开发观察，保留集60题用于冻结确认；两者分别报告。保留集结果不用于调 rerank 参数。其它方法配对和指标只作描述性结果，不能替换主要比较。

## 解释边界

Pooled Recall 是对已判池化候选的召回，不是对全语料穷尽相关性的召回。该实验只评测重庆资料文本与问题的相关性，不验证资料事实、不代表全国质量。跨模型一致率不能推导标签正确率；AI 评分只能用于优先发现检索问题和规划后续人工复核。
