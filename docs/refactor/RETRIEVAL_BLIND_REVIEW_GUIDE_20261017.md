# 本轮人工盲标说明

标注入口在交付目录的 `pool-01/annotation.html`。用本机浏览器打开即可，无需账号、后端或联网。建议先阅读本说明，再打开页面；标注时不要同时查看 `private-pool-map.json`、原始rankings或旧正例名单。

## 判断的对象

评价“这段冻结文本对这个问题的主体和属性有多相关”，不是评价它今天是否真实、网站是否权威、你是否喜欢该景点。文字中的 `verified` 不自动加分；过期资料在本轮文本检索实验中也不是自动0分。

| 等级 | 含义 | 通用例子 |
|---|---|---|
| 未判 | 尚未读完，或暂未决定 | 保持未判，不用0代替 |
| 0 | 不相关，或只碰到名称/主题却未提供所问属性 | 问某馆有没有电梯，资料只介绍该馆地址；或资料说的是另一个馆 |
| 1 | 回答部分必要属性，有具体帮助但不能完整回答 | 同时问票价和停票时间，资料只写票价 |
| 2 | 对正确主体直接回答问题 | 问有没有语音导览，资料明确说不提供；明确否定也可直接回答 |

同名、别名与主馆/分馆需要核对主体，不能把另一馆规定套用。只说“适合老人”并不能直接证明“某个入口有电梯”。相关文档可以不止一篇；不要因为已经给了一篇2分就把其他也能回答的文档打0。

对时间问题按题意判断：问资料里的常规时段，正文列出该时段就可以相关；问某公告公布了什么，可以评价公告内容是否对应；只有一般介绍不能证明今天实际发生。不要替正文补充外部常识，也不要因为自己知道现实答案就给没有相应内容的资料加分。

这是新的0/1/2分级，不直接沿用旧题草案0/1/2/3。若介于两个等级之间，填写理由，留待裁定；不要为了赶进度批量把未判变成0。

## 保存与续标

1. 页面只显示匿名题号和候选，没有方法、排名或旧金标。逐题选择等级；有争议时填写理由。
2. 填写实际复核者姓名，点“导出标注”。导出文件仅保存到本机，不上传；姓名是自述，工具不会认证身份。
3. **页面不自动保存。** 每完成少量题就导出一次；刷新/关闭前务必导出，确认浏览器下载确实完成。
4. 以后打开同一页面，选择“导入续标”载入最近的导出JSON。题文或候选版本改变会拒绝旧文件，不能手工改hash强行续标。
5. 未完成时可以导出，未判仍是null。整题候选判完才计该题指标；覆盖率会显示，不把部分完成说成80题已全部验收。

如果由AI辅助而没有人工逐项复核，不应填写人类声明或把它称为人工金标。请保留原始导出，不覆盖历史版本；需要更正时另存新文件并记录理由。

## 标注后计算

使用同一次运行的rankings、同一候选池和私有映射：

```powershell
node tools/ai-evaluation/retrieval-pool-score.mjs --rankings docs/refactor/evidence/retrieval-pooling-20261017/run-01/rankings.json --pool docs/refactor/evidence/retrieval-pooling-20261017/pool-01/blind-pool.json --mapping docs/refactor/evidence/retrieval-pooling-20261017/pool-01/private-pool-map.json --annotations <本轮真实人工导出JSON路径> --output <新的评分结果路径>
```

评分得到的是这个候选池下的nDCG、pooledRecall和MRR，不是穷尽全库召回或现实准确率。四组主方法和字符二元组消融的胜负要在完成标注后看，不能先看哪种方法检索到它再决定等级。
