# V6门禁最终收尾约定

本约定在新题集命题和实测之前声明，不改变V5未通过结论。门禁在V6三轮后停止质量迭代，不因未满分无限补题/补提示；剩余限制和人审待办保留，随后转多轮续接确定性回退。

## 本轮修复边界

1. 同城已核验目录身份（城市、catalog ID、问句mention、规范名、别名）在问题抽取并经现有完整名称解析后，作为可信受限元数据供证据判断。仅明确出现在原问的目录名/别名可参与，跨城/歧义不授权。新增IDENTITY结论；目录证据仅能支撑IDENTITY，不支撑政策、资格或现场状态。
2. Support新增evidenceState=SUPPORTED_VALUE/STATED_NEGATIVE/NOT_STATED。无资料与明确否定分开，Java把NOT_STATED固定为UNKNOWN；字段缺失/非法不放行。旧构造缺字段默认NOT_STATED。
3. ELIGIBILITY新增policyShape=CONJUNCTION/ALTERNATIVES/UNKNOWN。OR替代结构不在本轮支持范围；ALTERNATIVES或UNKNOWN均不裁个人资格，已知规则仍可回答。第一阶段无资料，结构识别必须放在证据阶段，不伪称事先知道资料结构。该分类仍依赖模型，结构化字段不是完整逻辑证明。
4. 用户已知背景不是必须重复的新请求；可以附带常规资料，但不能据此声称特定日临时公告存在。

## V6评价方式和退出标准

独立命题，50事实题（含多属性、身份、资料缺值/明确否定/OR边界）、10对话题，冻结题集和实现，三轮不改代码/提示/gold。语义模型实调、预选证据，0温度、关闭thinking；供应商失败不剔除，记录逻辑调用、tokens、p50/p95。

保留简单自动对齐器；无法无歧义对齐或类型/覆盖有分歧时生成复核清单，不打造新的语义评分模型。每轮真实误放、误拒案例各≤2；非事实路由不泄漏事实；供应商不可用的受控回归零错误放行；**歧义项全部经过真实人类裁决**。未收到用户裁决只能PENDING_HUMAN，AI建议不冒充人工，也不自动判通过。

OR个人资格在本轮公开支持范围外，V6 gold须事先标UNKNOWN（同时规则可答），既有V5 gold及其分支能力缺口保持原样。模型若声称完整AND而资料实际OR，仍是真实错误，不因枚举字段存在即免责。

V6后无论是否达标，明确写ACCEPTED/NOT_ACCEPTED/PENDING_HUMAN，不宣传未经人工复核的修正后错误率；V5原始分数不变。整理一页纸对外说明，随后开始多轮追问回退，先扩充并走真实preview链路。
