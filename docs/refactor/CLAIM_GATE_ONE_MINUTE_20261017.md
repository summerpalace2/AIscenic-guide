# 门禁一分钟口述

我给旅行助手做了证据门禁，防止模型把相关资料当成确定答案。第一版用规则，原题修好后，独立题集仍大量误放，说明规则过拟合了。后来改成模型抽取问题需求、Java校验主体和引文，失败时返回未知。随后发现部分问题只能回答一半，又把门禁细化到结论级。最终三轮经用户逐项人工裁决，误放都是零，误拒分别为零、一、二条。我保留了原始自动成绩和失败案例；这些结果只代表当前评测范围，不代表所有旅游问题都可靠。

讲解时无需同时背全部中间数字；被追问时展开原始自动成绩、人审与无效试跑的区别。后一次有效测量已看过部分题，不能称全新未见集泛化；非固定模型快照、非真实全链浏览器首字延迟。正文是约一分钟口述草案，未实测个人语速。
