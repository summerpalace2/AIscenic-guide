# 真实检索实验：语料准入与预注册方案

2026-10-17，状态：PREPARATION / NOT_RUN。此文不代表模型已安装、官方资料已复核或向量检索已运行。

## 先做什么

复用现有知识资产做只读盘点，生成准入清单；不建立第二套生产知识库，不向运行库导入未复核资料。现有30篇控制集继续保留为脚手架基线，不作为本实验质量结论。

现有资源222篇，218篇集中于重庆，其他四城各1篇，不能宣称全国语料覆盖。来源符号ID需要能解析到来源注册信息，`verified`自述不能取代来源核验。失效资料不得用于回答当前状态。现有数据库的旧schema与当前源码契约需单独在隔离副本核验，不能直接跑生产初始化来凑环境。

## 语料入场规则

每篇保留：原始ID、文本SHA256、实体/城市、来源URL及发布主体、获取日期、适用时间、授权/允许使用范围、来源文件位置、版本/近重复组、复核状态。缺来源和日期的数据进入待核实清单，不能默认为已核验事实。实验分两档：探索性固定文本检索可以在现有资料上评价“是否找回文本中所述内容”，明确不证明现实正确性；当前事实验收才要求来源、有效期和事实金标准入。缺许可元数据不自动等于禁止本地盘点，也不自动授权公开正文。

扩展实验目标为至少200篇可追溯资料、至少40个实体，纳入正式多城切片的城市目标至少20篇，并展示每题同城候选数。这是覆盖目标，不阻塞现有重庆资产的探索性文本检索；不足切片标为不具代表性，不能以单篇城市得出全国结论。不用改写同文或编造政策补数；TopK接近全库时单独警示。

需要三类困难负例：同城相似实体同属性、同实体近重复内容、明确标记的旧版本。真实历史版本保留其发布日期；没有实际来源的控制性合成负例只能在独立合成分层中使用，不能伪装官方公告、不能与真实集混算。

来源复核后固定获取快照并记录使用限制。实验不自动公开整篇外部正文；可交付来源清单、哈希、必要片段和本地复现方法。任何外部URL只列候选时标为未核验。

## 切分与金标

先冻结语料与问题，再运行四组。开发问题/标注和保留问题/标注按实体/来源/近重复组隔离；同文分块不能跨到两边形成泄漏。全部四组索引均包含同一完整冻结语料，包括保留题相关文档；隔离的是调参和标注使用范围，不是从索引删除保留文档。保留集至少60题，覆盖全名、简称、口语改写、跨实体混淆、无答案、日期及版本问题；每题有分级相关文档ID和理由。由独立作者拟题，人工确认后才作为验收金标。AI标签未获确认时只能报告探索性结果。

每题区分“语义相关资料”与“可支撑当前结论资料”。旧版本可能语义相关，却不支撑当前开放状态。分别计分：文本相关任务保留历史版本，不先用有效期过滤；当前事实任务按统一asOf和发布规则过滤，并另做不预过滤版本冲突切片检测失效证据。禁止先过滤旧文再声称模型学会识别版本。

## 四组对比与生产链路

1. dense：真实本地embedding模型。
2. sparse：BM25或真实稀疏模型，必须明确是哪一种；不能把关键词LIKE称为稀疏向量主链。
3. hybrid：dense+sparse，融合算法及参数在开发集确定后冻结。
4. hybrid+rerank：同一融合候选交真实reranker。

每个任务内四组采用相同城市/发布规则及上述时间策略，相同分块与最终TopK（1/3/5/10）。主对比固定召回条目总预算20：dense预取20，sparse预取20，hybrid预取dense10+sparse10后去重融合（不足20不额外回填），rerank仅处理同一hybrid候选。额外20+20召回只能列为另一个预算40的消融，不能混入预算20主表；记录融合前条数、去重池大小和调用成本。

冻结chunkId、版本及证据span到chunk的映射后才报告chunk级指标；只有文档金标时chunk指标记NOT_SCORED。主表为去重文档级：同文档多个chunk得分取最高；融合先按chunk执行，最终按该规则聚合文档。最终排序去重，不足K不补假结果，Recall分母为相关文档总数，nDCG的理想序列来自完整分级金标，不能按实际返回数缩小。

锁定模型名称、精确revision、下载来源和许可证、向量维度、截断长度、归一化、分词器、融合公式、硬件/线程数与索引设置。可先用独立脚手架校验模型，但不能把独立实验当作已验证Java→向量库→rerank主链；最终须另有真实适配器、索引与请求回执证据。mock、供应商失败或local fallback必须单列，不准冒充四组之一。

## 指标与退出条件

- Recall@K、MRR、nDCG@K，保留逐题排名和金标；无答案题单独统计，不把空金标算满召回。
- 同城错主体、跨城市泄漏、失效版本进入答案证据的比例。
- p50/p95：查询embedding、召回、融合、rerank分项及端到端；冷启动与预热分开。记录资源使用和失败，失败不能剔除。
- 固定同题三次运行，记录确定性模型差异、超时和每题稳定性；重复运行不是三倍独立样本，区间按实体/来源或问题family聚类。区间/配对差异优于只报总平均。实验不预设“hybrid一定改善”。

探索阶段可以交付未核验来源语料上的固定文本排名，但不能满足以下真实质量验收标准。真实质量验收完成标准：来源准入及人工金标完成、四组真实运行及Java主链连通证据齐全、全部失败和随机20%通过题经过复核、结果可由哈希和固定命令复现。若混合检索没有改善同样交付结果，不靠持续调参换保留集刷分。质量数值阈值在开发集基线后、保留集运行前另行冻结；当前不宣称达标。
